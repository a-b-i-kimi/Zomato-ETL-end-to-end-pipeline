Zomato Restaurant ETL Pipeline

##Overview
End-to-end ETL pipeline built on the Zomato Bangalore dataset 
(51,000+ restaurants) using Python, Pandas, NumPy, and SQLite.

## Pipeline Flow
Extract → Transform → Load → Analyse → Visualise

## Tech Stack
- Python, Pandas, NumPy
- SQLite (Data Warehouse)
- Matplotlib (Visualisation)

## Key Insights
- BTM has the highest restaurant count (5,109)
- Table booking restaurants have highest avg rating (4.16)
- High-rated restaurants (≥4.0) cost 2x more (₹894 vs ₹448)
